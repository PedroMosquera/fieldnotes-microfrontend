# Fieldnotes Microfrontend

A practice shop composed of React, Vue, Svelte and Qwik sections. The shell owns shared state and an admin panel for observing updates and testing failure isolation. One repository, independent frontend builds, local mock product data.

The March to July 2024 Git timeline is a reconstructed learning exercise. Commit timestamps describe the exercise schedule, not the actual date the files were authored. Only tools available by the exercise's dependency cutoff are intended to be used.
